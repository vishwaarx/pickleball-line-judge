Line camera

This phone becomes one line judge. Put it low, on the extension of the line, looking straight down it.

Browser says the connection is not private?

That is expected: the Mac is offline and signs its own certificate. Tap Show details → visit this website (iPhone) or Advanced → Proceed (Android) once.

If the camera still will not open, install the certificate: download pickle-ca.pem, then iPhone: Settings → Profile Downloaded → Install, and Settings → General → About → Certificate Trust Settings → enable. Android: Settings → Security → Install a certificate → CA certificate.
